# Separate UI Demonstration Inputs

These fictional io-v0.1 requests support the [walkthrough](../../docs/ui-demo-walkthrough.md). They are distinct from the fixed 50-case dataset and contain no generated outputs. The business clock remains November 4, 2026, 20:30 Asia/Shanghai.

Use the matching scenario in live mode, enable the advanced JSON checkbox, paste one whole request and submit explicitly. The app supplies a new request ID. Expected statuses in manifest.json describe supported service paths, not actual model quality or guaranteed generation success. Template preview does not execute advanced requests.

The isolated verifier uses these requests with temporary storage and labelled test doubles; it does not call a model or contribute to real output counts.
