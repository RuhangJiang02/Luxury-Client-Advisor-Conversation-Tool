Use one row per substantive action. Keep earlier entries and original results intact. Split a step when it produces a distinct artifact or changes the tool version.

```markdown
| 099 | [Actual action; include date/time if recorded] | [Prompt, data, source files, configuration/version] | [Actual result and artifact links] | [Tool/model/agent and role] | User-managed; outside assistant scope |
```

For implementation and evaluation steps, include the following details in the row or a linked step note:

- Date/time and timezone, when available; never invent missing timestamps.
- Exact user request or prompt reference and relevant input files.
- Tool/model configuration and code/prompt version that affected the result.
- Output artifact, case IDs, run IDs, or observed failure.
- Evaluation or decision, including why a change was made.
- Before/after references when modifying a previously tested tool.
- Transcript and artifact links; screenshots are user-managed.
